# CS300 Assignment 1 — Profile Card

Name: Nick Broniec
Component chosen: Option A — Profile Card
Live site: https://github.com/ngbroniec/cs300-assignment-1

## Design choices
- Used a dark gradient page background with a light card to create contrast and make the card "pop."
- Roboto for the user's name, and Arial for the rest of the text.
- Circular avatar with an accent-colored border.
- For hover effects, the whole card lifts with a stronger shadow, the avatar scales slightly, and social links + button invert their colors, giving layered feedback at different levels.
- For the box model, there is a border-radius/border on avatar and card, space padding inside the card, margin-bottom used for vertical space.
